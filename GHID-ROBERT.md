# Ghidul lui Robert, pe o pagină

Porniți aplicația o dată, apoi o folosiți 10 minute pe săptămână și 15 minute la final de lună.

## Prima pornire

1. Descărcați programul: aici pe GitHub, tabul **Actions → Program Windows (.exe)** → ultima rulare verde →
   **TestifyHardware-Windows**. Dezarhivați într-un folder, de exemplu `Documente\Testify`.
2. Dublu-click pe **TestifyHardware.exe**. Dacă Windows afișează „Windows protected your PC”:
   **More info → Run anyway**.
3. Alegeți parola (cel puțin 8 caractere) și notați pe hârtie **codul de recuperare**. Fără el, o parolă
   uitată nu se mai poate schimba. Prima pornire se face de pe calculatorul de la birou.
4. Lăsați fereastra neagră deschisă cât lucrați. Dacă o închideți, aplicația se oprește.

## În fiecare săptămână

- **Vânzări:** emiteți facturile sau treceți totalul pe zi; bifați „Încasat” când intră banii.
- **Cheltuieli:** „Citește bonul” (o poză) sau completați de mână. Facturile din SPV: Setări → Import e-Factura.
- **Stoc:** „Recepție marfă” când vine marfa; tabul „Comenzi recomandate” vă spune ce să comandați.
- **Trezorerie:** actualizați soldul din bancă și casă, ca prognoza să fie corectă.

## La final de lună

1. Rapoarte → **Descarcă Excel** sau **PDF** și trimiteți-l contabilului.
2. Calendar fiscal: vedeți ce e de plătit pe 25 și bifați „Am plătit” după plată.
3. Rapoarte → **Închide luna**, ca cifrele trimise să nu se mai schimbe. Încasările se pot bifa și după.
4. Opțional: **Scrisoarea lunii**, pentru parteneri sau bancă.

## Siguranța datelor

- Datele și copiile zilnice stau în folderul **TestifyData**, lângă program.
- O dată pe lună: Setări → Copii de siguranță → **Export complet (ZIP)**, pus pe un stick sau în cloud.
- Pe telefon: aceeași rețea Wi-Fi, adresa `http://<adresa calculatorului>:8000`, apoi „Adaugă pe ecranul
  principal”. Pentru intrare rapidă, setați un PIN din Setări.
- Aplicația se blochează singură după 15 minute fără activitate.
- Dacă pierdeți telefonul: schimbați parola din Setări; toate celelalte dispozitive ies din aplicație.

**Opțional: Testi cu AI.** Setări → Testi cu inteligență artificială → lipiți cheia API Anthropic. Cheia nu
se pune niciodată pe GitHub și nu se trimite pe email; nu intră nici în copiile de siguranță.
